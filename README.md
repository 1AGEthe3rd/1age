## Mission

1AGE is an open-source platform dedicated to making the Solana ecosystem easier to discover, navigate, and contribute to.

Our goal is to organize projects, opportunities, communities, tools, games, and builders into one accessible ecosystem.

---

## Current Status

🚧 Active Development

This repository contains the public 1AGE website: search, cosmic globe navigation
and linked ecosystem pages. The homepage ends at the orbit controls. Browser tab
identity is the green signal-1 favicon followed by AGE.

Preview locally with `python3 -m http.server 8000 --bind 127.0.0.1`, then open
http://127.0.0.1:8000 on that computer. The public deployment uses the existing
GitHub Pages main branch and 1age.com domain, when configured in repository settings.

Enter 1AGEWorld opens the installed desktop through its oneage: link handler.
Full browser 3D and Plus payments remain in development.
