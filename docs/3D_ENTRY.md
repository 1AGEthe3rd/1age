# Direct application entry into 1AGE World

Homepage Enter links for World, Games, Page, Space, Exchange, Quest, Cash and Design now use `oneage://world/enter?destination=<id>`. The main homepage retains the backward-compatible `oneage://world/enter`. The corresponding World runtime changes are reviewed in private repository `1AGEthe3rd/1age-world`, branch `feature/world-domes-destinations`, draft PR #5.

Games launches its existing Games Complex. The other five flagship apps arrive directly inside their named glass pavilions; these are environmental foundations, not complete online financial/profile/social services. Design opens the existing builder on the orbital environment. World opens the orbital arrival without the old Room 001 lobby.

Plus, App, Store and Shop have no established 3D scenes. Their globe action remains an honest Open app link to their existing workspace. No fictitious native destination is advertised.

## Deployment dependencies

1. Install the reviewed World revision and run `python3 launcher/install_links.py` on each Linux laptop. The installer backs up the prior current-user URI registration.
2. Publish these web changes through the existing GitHub Pages review process. The new links require the new native handler; an old handler may reject destination query parameters.
3. Test one homepage Enter link on each configured device. Browser permission to open a native application can still be required.

The native source includes `launcher/usb_transfer.py prepare` to copy a checksum-verified canonical runtime revision and Godot binary to a jump drive. The offline installer copies them locally and registers Enter links on the second laptop. It does not export a browser game or enable phone play. No tokens, paid hosting, new DNS records or private source are deployed by this website change.

The registrar is Porkbun. The owner confirmed Exchange's current registration through 2027-04-30; the earlier Namecheap notice was not reliable evidence of expiration. Domain routing/hosting verification remains separate.
