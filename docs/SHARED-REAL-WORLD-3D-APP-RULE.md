# 1AGE World × Independent 3D App Environment — Founder-Approved Standard

**Decision date: November 23, 2026.**

## Permanent design rule

Every 1AGE destination must use the **real 1AGE World cosmic environment** as its shared visual/world foundation where applicable, while remaining its **own independent, functional 3D platform**.

Do not create disconnected generic 3D prototypes and present them as 1AGE World. In particular, do **not** substitute an unrelated glowing globe, approximate Earth, random synthetic stars, fake orbital ring, a hollow showroom, or an empty environment when real approved 1AGE World content or existing app functionality already exists.

Use the approved *actual* World Earth, existing rotating globe animation, orbital ring, original cosmic sky, original six platforms, and approved controls. When true astronomical star positions are required, use accurately sourced public/appropriately licensed astronomical catalogs rather than random procedural stars. The approved World's existing star visuals are authentic to its release, but scientific accuracy has not yet been verified.

The approved World browser export lives in **1AGEthe3rd/1age-world-web** at commit **66ead0e5d68fe78370c07f67e515e2a6e2d1c9c0**. Its source Godot scene `world_build0082.tscn` was not found in inspected GitHub trees. Do not re-create or alter World without the editable original and explicit founder approval.

## Platform independence

Every app launches on **its own domain** and must retain its real, useful functionality, identity and interfaces. The environment is **shared**, not a reason to replace all applications with a World iframe.

- **Cash**: real Account/Balance/Activity and approved internal payments, with the original 1AGE World rendered as its visual environment until a native scene integration is available. No fake credit balances.
- **Page**: its native orbital social identity, people discovery and external social portals; do not replace the profile system with a generic room or walkable FPS scene.
- **Space**: its existing independently navigable commercial property scenes and HQ1 3D Portland neighborhood; World portals should connect these, not destroy them.
- **Games/NNB**: existing branded boxing gym/other games, preserving gameplay and transport to HQ1/World.
- **Exchange, Quest, Design, Plus, Store, Blog and other destinations**: preserve implemented interactive scenes, data and functionality as their foundation, and link to genuine World destinations. No unverified scenes masquerading as live products.

Integration may take different forms: genuine shared Godot asset/scene inclusion where editable source is verified; safe World portals from existing independently rendered apps; or a **read-only real World iframe** with native app-specific foreground UI as an interim measure. An iframe alone does not establish programmatic accounts, payments or synchronized cross-app player states.

## Unalterable protection requirements

1. Read remote repository HEADs and all existing approved scenes/functions before changing anything.
2. Build from the latest compatible source; never force-push, reset, or overwrite approved work.
3. Do not replace an actual scene with generic fallback geometry even if source integration is hard. Report missing source instead.
4. Use the **original** World rotating Earth and original sky, rather than inventing a second approximation; no duplicate on-screen gamepads.
5. Store any 1AGE Cash balances and auth only on the appropriate secure backend. Never expose secrets to a cross-origin World iframe or URL.
6. Render the **actual integrated runtime** for desktop, iPhone portrait/landscape and relevant gamepad, rather than showing concept renders as proof.
7. Keep all improvements in feature branches and draft PRs. Founder reviews the actual 3D visuals **before production publishing**.
8. Do not edit the production World export, 1AGE.com, app domains or payments merely to enforce this standard; each change needs its own approved scope.

## Verification checklist

- [ ] Does the user actually see the original World rotating globe and cosmic sky, or preserved original app scene linked to it?
- [ ] Are stars genuine from the approved World release (or independently verified catalog data), not random placeholders?
- [ ] Are real existing app features preserved, navigable and tested?
- [ ] Does each app still open on its own domain and offer its own functions?
- [ ] Is World navigation integrated honestly, without asserting unavailable cross-origin bridges?
- [ ] Are original controls/gamepad behavior intact?
- [ ] Have actual desktop/mobile scenes been rendered and approved?

**Founder direction:** "Always use the real 1AGE World environment, the real rotating globe and real stars. Every app connects to its own platform; do not replace completed work with generic 3D scenery."
