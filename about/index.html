ABOUT 1AGE

Search the blockchain community.

1AGE is a blockchain search engine and connected application ecosystem for all blockchains. It is a Solana-based infrastructure project with a multichain purpose.

Built on Solana. Open to every blockchain.

Solana is the infrastructure foundation. Search and application participation extend across blockchains, helping people discover projects, communities, builders, tools, games and opportunities.

The index grows through research and review. A multichain purpose does not mean that every blockchain or project is already indexed. Listings are not endorsements or security audits.

What you can use today.

This website includes blockchain search, the rotating application dial, application entrances and browser-local workspaces. Those workspaces include profile editing, space links, design previews, a local game, objectives and a demonstration ledger.

Shared accounts, messaging, wallet connections, payments, property claims and real rewards require further development. Browser-local data does not automatically follow you across devices.

Visit the separately released 1AGE World browser experience. Hosting and domain connections are being organized alongside the existing desktop entry paths.
