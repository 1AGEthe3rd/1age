COMMON QUESTIONS

Get to know 1AGE.

Clear answers about what you can use today and what is being built.

What is 1AGE?

1AGE is a discovery platform organizing the Solana ecosystem, with connected web applications and an immersive World in development.

Is 1AGE only a search engine?

Search is a primary entry point. The wider platform connects identity, social experiences, games, commerce, learning and creation.

Do I need a wallet to browse?

You can search this directory and read the public pages without connecting a wallet.

Do I need an avatar?

No avatar is required to use the current website. Avatars belong to the planned immersive experiences.

Can I join 1AGE Plus now?

Not yet. Member benefits, payment details, renewal and refund terms will be published before payments open.

Is the browser World available?

The homepage offers globe navigation. A full immersive browser room is still in development.

Who builds 1AGE?

1AGEthe3rd is the studio developing the platform.

Does the directory cover everything on Solana?

No. The current directory is an early, small collection. A listing is not an endorsement or a claim that a project has been audited.
