# 1AGE Online — foundation 021
Independent walkable global multiplayer command center. This is a disconnected client foundation, with presence, friends, destination discovery and privacy preference preview. No fabricated users, counts or sessions; no real status is published. Future authoritative presence service: authenticate with shared Page identity, heartbeat and expire sessions, enforce user-selected audience and invisible/busy behavior server-side, disclose only permitted coarse destination counts, require explicit invitation/join consent and access checks. Actual movement synchronization needs authoritative server sessions, interpolation, rate limits, anti-abuse, moderation and load tests. Separate proposed 1AGE Live handles broadcasts/events, not multiplayer identity. No backend, voice, messaging or session joining is active.
