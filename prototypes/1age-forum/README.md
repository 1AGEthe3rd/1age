# Spatial Design 014 — Global community forum
Separate prototype under prototypes/1age-forum in the central repository because no accessible standalone Forum repo exists. Do not merge this into the homepage; migrate to dedicated 1age-forum repository with compatible shared assets after creation. Four stations: global discovery, local communities, discussion lounges, community studio. Synthetic category browser and unsaved thread composer; no public posting, user accounts, community membership or multiplayer.
Forum is open to all topics, distinct from Blog long-form publishing. Future Page identity, community creation, threaded replies, article-ID references, search, moderation roles, report/block/mute, anti-spam, privacy, appeal and deletion flows. Local community discovery uses public city/topic selection, not compulsory precise location. No rewards, payments or token gating. Link to existing Blog, not fabricated publications. 
Pinned Quest walking/architecture foundation, existing central assets. Browser/controller/render testing pending; production unchanged; World Forum platform remains non-navigating until a real destination exists.
